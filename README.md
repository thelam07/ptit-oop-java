# ptit-oop-java

Bài giải các bài tập Java trên [code.ptit.edu.vn](https://code.ptit.edu.vn) —
môn **Lập trình hướng đối tượng (OOP)**, Học viện Công nghệ Bưu chính Viễn thông (PTIT).

## Danh sách bài

| Mã bài | Tên bài | Kiến thức chính |
|--------|---------|-----------------|
| J01001 | Hình chữ nhật | class, đóng gói, constructor, phương thức |
| J01002 | Tổng N số nguyên dương đầu tiên | công thức Gauss, tràn số `long` |
| J01003 | Giải phương trình bậc nhất | rẽ nhánh lồng nhau, `printf` định dạng |
| J01004 | Số nguyên tố | vòng lặp tới `√n`, kiểm tra biên |
| J01005 | Chia tam giác | tam giác đồng dạng, `double`, `Math.sqrt` |
| J01006 | Tính số Fibonacci | lặp 2 biến, giới hạn `long` |
| J01007 | Kiểm tra số Fibonacci | sinh dãy bằng `while` |
| J01008 | Phân tích thừa số nguyên tố | chia dần, phần dư còn lại là số nguyên tố |
| J01009 | Tổng giai thừa | tích lũy, phần tử đơn vị |
| J01010 | Cắt đôi | xử lý chuỗi, `charAt`, `substring` |
| J01011 | BSCNN / ƯCLN | thuật toán Euclid |
| J01012 | Ước số chia hết cho 2 | đếm ước theo cặp `(i, n/i)` |

## Cách chạy

```bash
javac J01001.java
java J01001
```

> Lưu ý khi nộp trên code.ptit.edu.vn: **không khai báo `package`**, và tên class `public`
> phải trùng với tên file.
